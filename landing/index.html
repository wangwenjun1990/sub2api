A FEW THINGS TO KNOW.

开始之前，
你可能还想知道。

有具体的接入问题？我们一起看看。

聊聊你的问题
鹊桥是聊天软件，还是 API 服务？

鹊桥提供 AI 模型 API 接入与用量管理。你可以把 API Key 配置到支持自定义接口的客户端、开发工具或自己的应用里使用。页面中的灵感实验室是场景演示。

第一次使用，需要写代码吗？

如果你使用支持自定义 API 地址的客户端，通常只需填写 API 地址、Key 和模型 ID。开发者也可以通过兼容 OpenAI 格式的 SDK 或 HTTP 请求接入。不同工具的设置方法以对应工具说明为准。

支持哪些模型？怎么查看价格？

登录控制台查看当前可用的模型和计费规则。具体型号、分组与输入、输出单价以控制台为准，可以先确认适合自己的模型，再按需充值。

怎么知道一次请求花了多少钱？

控制台的用量日志会记录请求使用的模型、Token 和费用明细。不同模型的计费规则可能不同，充值前可以先查看单价与分组倍率。
